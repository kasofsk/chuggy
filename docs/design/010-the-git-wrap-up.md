# The git wrap-up

**Status: LANDED** — R6 has landed; kasofsk/chuggy#72 was the ticket.

For a ticket wrapping up exclusively, the gate is the merge. The tree carries the decision: `src/runtime/followUps.ts` states why the dequeue always draws moved, and `src/adapters/gitWrapUp/` is the performer, its headers stating the attempt, the re-answer discipline and the conflict pricing.

## What the tree does not yet carry

The repositories are to live behind the git service (doc 013), which serves bytes and enforces ref scope while deciding nothing; the performer then pushes with the sole credential allowed to move a default branch, where today it pushes to whatever remote it is configured with. A signature, once key infrastructure exists, is the machine's — never the author's — because a job or a merge that could hold a person's signing key could sign as that person.

## What would refute the recovery position

No lease timeout exists in this design, and the pre-named trigger stands: the day the attempt leaves the process, the crash seam stops being writable as a function, and that day is a model commit rather than an adapter patch.
